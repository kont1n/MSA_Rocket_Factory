## 📝 Полезные команды

```bash
# Запустить тесты с покрытием
task test-coverage

# Сгенерировать HTML отчет
task coverage:html

# Проверить покрытие конкретного модуля
cd order && go test -cover ./internal/...

# Найти файлы без покрытия
go tool cover -func=coverage/coverage_order.out | grep "0.0%"

# Запустить тесты конкретного пакета
go test -v ./order/internal/api/order/v1/...
```
